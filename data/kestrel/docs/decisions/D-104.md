# Move PDF rendering to an async queue

Context: Every invoice save renders a PDF synchronously before responding.
Decision: Move PDF rendering to an async queue.
Project: Async PDF rendering.
Why: PDF rendering is the largest share of API latency.
Options considered and not chosen: Buy a faster PDF library; Render PDFs on the client.
Risks: users may download a PDF before it is ready.
Success means api p95 latency changes by -25.0% from its pre-launch level by 2026-01-26. Owner of the result: Aarav Sharma.
