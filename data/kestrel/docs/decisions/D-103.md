# Precompute dashboard aggregates

Context: Dashboard requests are slow and share the invoice API.
Decision: Precompute dashboard aggregates.
Project: Precomputed dashboard aggregates.
Why: Invoice API traffic is read-heavy, so caching reads cuts latency.
Options considered and not chosen: Move dashboards to the warehouse; Cache the dashboard endpoint.
Risks: aggregates may lag behind real-time invoice changes.
Success means api p95 latency changes by -15.0% from its pre-launch level by 2026-12-07. Owner of the result: Chloe Weber.
