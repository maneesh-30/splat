# Cache invoice reads in Redis

Context: p95 latency on the invoice list has crept up to over 400 ms and is the top complaint from large accounts.
Decision: Cache invoice reads in Redis.
Project: Invoice read cache.
Why: Invoice API traffic is read-heavy, so caching reads cuts latency.
Options considered and not chosen: Add read replicas; Paginate the invoice list more aggressively.
Risks: cache invalidation bugs could show stale invoice totals.
Success means api p95 latency changes by -30.0% from its pre-launch level by 2026-04-20. Owner of the result: Aarav Sharma.
