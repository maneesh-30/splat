# Cache customer profile lookups

Context: Customer profile lookups run on almost every invoice request.
Decision: Cache customer profile lookups.
Project: Customer profile cache.
Why: Invoice API traffic is read-heavy, so caching reads cuts latency.
Options considered and not chosen: Denormalise profile fields onto invoices; Do nothing until the Go rewrite.
Risks: profiles change rarely but address changes must show immediately.
Success means api p95 latency changes by -20.0% from its pre-launch level by 2026-06-22. Owner of the result: Neha Moreau.
